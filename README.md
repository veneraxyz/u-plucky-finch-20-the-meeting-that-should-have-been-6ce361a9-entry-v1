A Node 22 TypeScript program (`main.ts`, stdlib only) that writes exactly one
line — the funniest one-liner about a meeting that should have been an email —
to `entry.txt` in the output directory given by `MAKEFUN_OUTPUT_DIR`
(falling back to `/output`).

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```
